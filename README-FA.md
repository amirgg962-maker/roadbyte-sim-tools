# پچ رفع خطای Git Hooks در ویندوز

## مشکل چه بود؟
در `package.json` اسکریپت `prepare` به شکل `sh scripts/install-githooks.sh` اجرا می‌شد. در ویندوز اگر `sh` در PATH نباشد خطا می‌دهد. همچنین فایل ZIP دانلودشده از GitHub معمولاً پوشهٔ `.git` ندارد و اصلاً نیازی به نصب Git hooks ندارد.

## اعمال پچ
1. برنامه را ببندید و در ترمینال اجرای `pnpm.cmd tauri dev` را با `Ctrl+C` متوقف کنید.
2. از `package.json` فعلی نسخهٔ پشتیبان بگیرید.
3. محتویات ZIP را در ریشهٔ پروژه (همان پوشه‌ای که `package.json` در آن قرار دارد) استخراج و فایل‌ها را جایگزین کنید.
4. در PowerShell از ریشهٔ پروژه اجرا کنید:

```powershell
pnpm.cmd install
```

5. سپس بررسی کنید:

```powershell
pnpm.cmd check-types
cargo test --workspace
```

## رفتار جدید
- اگر پوشهٔ `.git` وجود نداشته باشد (مثلاً پروژه از ZIP استخراج شده)، Git hooks رد می‌شوند و نصب وابستگی‌ها بدون این خطا ادامه می‌یابد.
- اگر پروژه یک checkout واقعی Git و پوشهٔ `.githooks` موجود باشد، برنامه سعی می‌کند `core.hooksPath` را روی `.githooks` تنظیم کند.
- اگر Git نصب نشده یا قابل‌شناسایی نباشد، فقط هشدار می‌دهد و نصب وابستگی‌ها را متوقف نمی‌کند.
