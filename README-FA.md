# Roadbyte Sim Tools

**ابزاری دسکتاپ برای مدیریت پروفایل‌ها، فایل‌های ذخیره و تنظیمات Euro Truck Simulator 2**

Roadbyte Sim Tools به شما کمک می‌کند پروفایل‌ها و سیوها را ببینید، اطلاعات پیشرفت را بررسی کنید، مقادیر پشتیبانی‌شده را ویرایش کنید، سیوها را مدیریت کنید و بعضی تنظیمات `config.cfg` را تغییر دهید.

> Roadbyte Sim Tools یک ابزار مستقل و ساخته‌شده توسط جامعهٔ کاربران است و وابستگی یا تأییدی از طرف SCS Software ندارد.

برای بیشتر رایانه‌های ویندوزی، در صفحهٔ انتشار فایل **`.msi`** را انتخاب کنید. فایل نصب **`.exe`** جایگزین آن است. فایل‌های `.sig` و `latest.json` نصب‌کننده نیستند؛ آن‌ها برای بررسی و ارائهٔ به‌روزرسانی استفاده می‌شوند.

## قابلیت‌ها

- **مرور پروفایل و سیو:** یافتن پروفایل‌ها و سیوها و مشاهدهٔ اطلاعات پیشرفت موجود.
- **ویرایش سیو:** تغییر پول و XP پشتیبانی‌شده و اجرای بعضی عملیات سریع.
- **انتخاب بازی:** جابه‌جایی میان کشف پروفایل و تنظیمات ETS2 و پشتیبانی اولیهٔ ATS؛ ویرایش سیو و سازگاری ATS هنوز با سیو واقعی اعتبارسنجی نشده است.
- **مدیریت سیو:** تغییر نام، کپی و حذف فایل‌های ذخیره.
- **ویرایش تنظیمات:** جست‌وجو و ویرایش `config.cfg` با بررسی نوع داده، راهنمای دارای منبع، کنترل عددی محتاطانه و راهنمای بازیابی فایل.
- **پشتیبان‌ها:** ساخت و بررسی پشتیبان، مقایسهٔ پیشرفت سیوها و آزمایش بازیابی در پوشهٔ موقت.
- **الگوهای تنظیمات:** ذخیره و پیش‌نمایش پروفایل تنظیمات به‌صورت محلی؛ مقادیر حساس و مسیرها در الگو ثبت نمی‌شوند.
- **ویرایش ایمن‌تر:** برنامه ابتدا در حالت فقط‌خواندنی باز می‌شود و ویرایش باید جداگانه فعال شود.
- **اطلاعات سازگاری:** نمایش اطلاعات بازی و هشدار دربارهٔ نسخه‌های پشتیبانی‌شده.
- **راهنمای شروع و عیب‌یابی:** راهنمای قابل‌بازگشایی و خروجی تشخیصی پاک‌سازی‌شده که خودکار ارسال نمی‌شود.

قابلیت‌ها ممکن است به فرمت سیو و نسخهٔ بازی بستگی داشته باشند. پیش از ویرایش، از پروفایل‌های مهم خود یک نسخهٔ پشتیبان جداگانه بگیرید.

## نصب

1. صفحهٔ [انتشارهای GitHub](https://github.com/amirgg962-maker/roadbyte-sim-tools/releases/latest) را باز کنید.
2. در ویندوز فایل نصب **`.msi`** را دانلود کنید. اگر MSI برای سیستم شما کار نکرد، فایل نصب **`x64-setup.exe`** را امتحان کنید.
3. نصب‌کننده را اجرا کنید و مراحل آن را ادامه دهید.

بسته‌های Linux هم در همان صفحه هستند؛ بستهٔ متناسب با پردازندهٔ خود را انتخاب کنید. فایل‌های `.sig` امضای دیجیتال هستند و برنامه نیستند.

بسته‌های امضاشدهٔ updater و فید عمومی `latest.json` همراه انتشارها منتشر می‌شوند. برنامه از مسیر **تنظیمات ← به‌روزرسانی برنامه** نسخهٔ جدید را بررسی می‌کند. فایل‌های انتشار و فید نسخهٔ فعلی در دسترس‌اند؛ اگر به‌روزرسانی درون‌برنامه‌ای خطا داد یا پس از راه‌اندازی دوباره شمارهٔ نسخه تغییر نکرد، آخرین نصب‌کننده را دستی از صفحهٔ انتشار دریافت کنید.

## ساخت از کد منبع

برنامه با React، TypeScript، Vite، Tauri 2، Rust و pnpm ساخته شده است. [پیش‌نیازهای Tauri](https://v2.tauri.app/start/prerequisites/)، Node.js، Rust و نسخهٔ مشخص‌شدهٔ pnpm یعنی `pnpm@11.11.0` را نصب کنید.

از ریشهٔ مخزن اجرا کنید:

```sh
pnpm install
pnpm tauri dev
```

برای ساخت رابط کاربری و بررسی TypeScript:

```sh
pnpm build
```

برای ساخت نصب‌کنندهٔ دسکتاپ، پیش‌نیازهای بسته‌بندی Tauri برای سیستم‌عامل خود را نصب و اجرا کنید:

```sh
pnpm tauri build
```

برای معماری پروژه، اجرای بررسی‌ها و مشارکت، [راهنمای انگلیسی مشارکت](CONTRIBUTING.md) را ببینید.

## ایمنی و سازگاری

ویرایش سیو فایل‌های محلی بازی را تغییر می‌دهد و ممکن است با به‌روزرسانی‌های بازی، مادها یا ابزارهای دیگر تداخل داشته باشد. پیش از ویرایش نسخهٔ پشتیبان جداگانه تهیه کنید. Roadbyte Sim Tools برای مدیریت محلی پروفایل و تنظیمات است و برای دورزدن ضدتقلب یا محدودیت‌های چندنفره طراحی نشده است. فایل سیو واقعی یا گزارش‌های بدون حذف اطلاعات شخصی را در گزارش عمومی باگ بارگذاری نکنید.

ویرایش سیو فشرده، فایل را به قالب متنی `SiiN` می‌نویسد. برای اینکه بازی در ذخیره‌های بعدی هم قالب متنی را حفظ کند، `g_save_format` را روی `2` بگذارید. فایل‌های دودویی `BSII` همچنان پشتیبانی نمی‌شوند.
